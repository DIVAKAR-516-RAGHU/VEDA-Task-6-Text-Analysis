# VEDA AI & ML Internship – Task 6: Text Analysis

## Objective

The objective of this task is to analyze a given text and calculate:

- Number of words
- Number of characters
- Number of vowels
- Repeated words and their frequency

## Tools Used

- Python
- Jupyter Notebook

## Concepts Used

- String processing
- Regular expressions
- Tokenization
- `len()`
- Dictionary
- `collections.Counter`

## Features

The program performs the following operations:

1. Accepts a sample text.
2. Converts the text to lowercase.
3. Extracts individual words.
4. Counts the total number of words.
5. Counts the number of characters.
6. Counts vowels.
7. Identifies repeated words.
8. Calculates word frequency.

## Sample Text

Artificial intelligence is transforming technology.

Artificial intelligence helps computers learn from data.

Python is widely used in artificial intelligence and data analysis.

Python makes data analysis simple and practical.

Interview Questions
1. What is text preprocessing?

Text preprocessing is the process of cleaning and preparing raw text before analysis or machine learning.

Examples include lowercase conversion, tokenization, removing unwanted characters, stop-word removal, stemming, and lemmatization.

2. How can repeated words be identified?

Repeated words can be identified by counting the frequency of each word using a dictionary or Python's Counter.

Words with a frequency greater than one are considered repeated words.

3. What is NLP?

NLP stands for Natural Language Processing.

It is a field of Artificial Intelligence that enables computers to process, understand, analyze, and generate human language.
